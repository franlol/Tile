# Tile

Raid frames for healers in WoW Forever: indicators drawn with the game's
native auras, and profiles per group size.

## Features

- **Indicators**: icons, squares, bars, texts, borders and tints at any spot of
  the frame. The game draws the auras itself, so they work in combat and in
  instances.
- **Spell catalog** per class: add common buffs and debuffs as indicators in a
  few clicks, or as "missing" warnings out of combat.
- **Dispellable and typed debuffs**, boss debuffs, shields and incoming heals.
- **Profiles per group size** (party, 10, 20, 40), with a test mode that
  simulates each size.
- **Instance guide**: bosses and their debuffs per dungeon and raid.
- Range fading, status texts (dead, offline, resurrecting, AFK...), ready
  check, role, leader and raid markers, pets.
- English and Spanish.

## Commands

- `/tile`: open the options
- `/tile unlock` / `/tile lock`: move the frames
- `/tile test`: test mode
- `/tile status`: active profile
- `/tile reset`: reset the frame positions
